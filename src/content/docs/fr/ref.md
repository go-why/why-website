# Référence

La référence suit l'ordre de `why.md`. Chaque page commence par le why du concept, reprend la phrase de la spec, un fragment, et le diagnostic quand la construction est refusée. Une construction écrite mais pas encore compilée est marquée `pas dans cette version`.

Les fichiers, le réseau, le JSON et le formatage sont une bibliothèque ; ils n'entrent pas dans la référence du langage.
